# 供应商图标资源

完整覆盖清单、2026-11-06 官方核对依据、固定上游链接、社区版本差异及品牌使用限制见 [供应商图标来源与覆盖](../../../../docs/PROVIDER-LOGOS.md)。当前有 14 份主资源；四个尚未解决品牌条件或现行图形的预设继续使用通用接口符号，不能视为全部官方图标已补齐。

- `svg/`：静态源图形；保留既有 DeepSeek、百炼、Grsai、用户确认 Meinianda 头像和通用接口符号。`grsai-dark.svg` 是既有附加反白派生，未计入 14 份主资源。
- `png-128/`：同名 128×128 透明 PNG，供卡片与管理页共享；运行时不解析 SVG、不远程取图。
- `manifest.json`：上游来源、固定版本、分类、派生文件哈希和供应商映射。
- `licenses/`：保留的 DeepSeek 软件许可参考、Lobe Icons MIT 和 Pollinations MIT 原文。版权许可不等于商标许可或官方授权。

New API、Sub2API 图形识别网关软件适配器类型，不表示用户配置的站点由上游运营。Grsai 为既有官网图片的矢量整理，Meinianda 为用户确认头像近似；本轮不为它们宣称新的开放许可。Vercel 商标声明及相关规范见上述正式说明。
