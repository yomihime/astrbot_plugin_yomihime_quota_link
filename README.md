# 如月怜的额度连结

AstrBot 多平台 AI API 余额 / 用量监控插件。

项目目标是将不同 AI 服务商的余额、调用量、套餐额度和重置时间统一整理，
并为查询、趋势展示与额度告警提供一致的入口。

> 当前状态：初始化阶段。现版本只提供插件加载检查命令，尚未接入真实平台。

## 功能规划

- 多平台 AI API 账号与凭据配置
- 余额、剩余额度、已用量与重置时间查询
- 统一的文本摘要与结构化展示
- 额度阈值告警与定时检查
- 平台适配器、缓存和错误状态隔离

## 安装

在 AstrBot WebUI 的插件管理中，使用以下仓库地址安装：

```text
https://github.com/yomihime/astrbot_plugin_yomihime_quota_link
```

安装后启用插件；更新时通过插件管理更新并重载。

## 使用

| 命令 | 说明 |
| --- | --- |
| `/yql` | 查看插件加载状态与当前开发阶段 |

命令前缀和唤醒方式以 AstrBot 配置为准。

## 开发

本项目面向 Python 3.12+ 和 AstrBot 4.16+。提交前建议运行：

```bash
ruff check .
ruff format --check .
```

插件持久化数据应写入 AstrBot 的 `data` 目录，不要写入插件源码目录。
网络请求应使用异步客户端，例如 `aiohttp` 或 `httpx`，避免阻塞 AstrBot 事件循环。
